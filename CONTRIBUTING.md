# Contributing

1. Fork the repository and create a focused branch.
2. Add original content or correct an existing entry. For directories, edit both the JSON catalog and README, preserve the schema, and include an official source URL.
3. Describe access limits, licensing and commercial-use restrictions accurately. Do not submit paid-only tools as free resources or copy third-party text.
4. Run `python3 -m unittest discover -s tests -v`.
5. Open a pull request explaining what changed and how you checked it.

Be respectful, disclose affiliations, and avoid promotional spam.
